# Developer Portfolio

A single-file, animated developer portfolio: a Three.js particle world that morphs through a scroll-driven story, a pinned horizontal work reel, service rows, a scroll-lit about statement and a contact section.

- Four colour themes (Scarlet, Dark Sunset, Paper Red, Sunset)
- English, Spanish, Urdu and Arabic (with RTL support)
- No build step: open `index.html` in a browser

All names, projects and contact details in the page are placeholders — replace them with your own.
